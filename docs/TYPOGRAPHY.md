# Policy Lens typography

Newsreader headings and DM Sans body text give the analysis lab an academic
editorial identity distinct from Agent Gate. Both variable fonts are self-hosted
Latin subsets, with SIL Open Font License notices beside the assets. Weight and
optical-size axes are retained.

CSS tokens establish an 18px base and 1.25 heading scale, with functional 16px
supporting text and 15px technical labels. Body line height is 1.6. Evidence
tables reflow into labeled records below 1100px, navigation becomes a two-column
mobile grid, and long report content wraps. Controls retain visible focus and
a minimum height of 44px.

Code-level review: hierarchy 4/5, distinctiveness 4/5, readability 4/5,
accessibility 4/5, polish 4/5. These are design judgments; browser viewport and
performance measurements are separate and have not been claimed.
